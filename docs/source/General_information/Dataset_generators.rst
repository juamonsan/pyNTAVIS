Dataset generators
====================



``pyNTAVIS`` incorporates different tools for generating datasets from a set of input files. The tools that convert
each whole file into a new representation are included in the :doc:`DatasetGenerators class <../pyNTAVIS.dataset_gen>`,
and the tools that split recordings into windows for training spiking neural networks (SNNs) are part of the
:doc:`Splitters <../pyNTAVIS.splitters>` and :doc:`Functions <../pyNTAVIS.functions>` classes. All of them work with
mono, stereo and three-axis files.


Whole-file dataset generators
-----------------------------

The ``DatasetGenerators`` class receives the path of a folder containing a set of AEDAT files (optionally including its
subfolders) and generates one output file per input file in a new folder. Currently, three dataset generators are
implemented:

- **Sonogram dataset generator** (``generate_sonogram_dataset()``): generates the sonogram of each file as a PNG image. This image dataset could be useful for training and testing CNNs or other deep learning algorithms on recognition tasks. This approach was previously used in *Dominguez-Morales, Juan P., et al. "Deep neural networks for the recognition and classification of heart murmurs using neuromorphic auditory sensors." IEEE transactions on biomedical circuits and systems 12.1 (2017): 24-34*.


- **Histogram dataset generator** (``generate_histogram_dataset()``): generates the histogram of each file in CSV format. Each CSV file has one row per address (``num_channels * (on_off_both + 1)`` addresses per source, for each cochlea or axis), with the number of spikes generated by that address. Therefore, the histogram represents the frequency response of the sensor for an input file. This could be useful for different scenarios and experiments. As an example, these values could be used as weights for the projections between the first and the second layer of an SNN in neuromorphic audio recognition tasks. A similar approach was used in *Dominguez-Morales, Juan Pedro, et al. "Multilayer spiking neural network for audio samples classification using SpiNNaker." International conference on artificial neural networks. Springer, Cham, 2016.*.


- **Phaselock dataset generator** (``generate_phaselock_dataset()``): generates a new AEDAT file with the phase-locked version of each file. When phase-locking, the ON and OFF spike streams of each channel are merged into a single stream, where a spike is generated only when the stream changes from ON to OFF. More information regarding this procedure can be read in the :doc:`Glossary <Glossary>`. The output files have fewer spikes than the original ones and one address per channel (instead of one per channel and polarity), so they must be loaded with **on_off_both=0**. They can be used for further processing, SNN training and many other tasks.


Window datasets for SNNs
------------------------

SNNs are usually trained with many short inputs of the same length rather than with whole recordings. ``pyNTAVIS``
provides two functions for this, which are applied to each recording of a dataset:

- **Window splitter** (``Splitters.window_splitter()``): splits a recording into fixed-length time windows, with an optional overlap between consecutive windows (set by the **stride**), and discards the windows with too few spikes. The windows can be returned as SpikesFiles or saved as new files (AEDAT, CSV or TXT), one per window, which creates a dataset of windows from a dataset of recordings.
- **Frames** (``Functions.spikes_to_frames()``): converts each window into a matrix of spike counts with one row per time step and one column per address, which is the usual input of SNN simulators trained with time steps (for example snnTorch, SpikingJelly or Norse).

For example, the NTAS-Fan experiments split every recording into 200 ms windows (50 % overlap for training, no
overlap for validation) and convert each window into 200 frames of 1 ms. The whole procedure is explained in the
:doc:`SNN example <../Examples/snn_frames>`, and the
`SNN training notebook <https://github.com/juamonsan/pyNTAVIS/blob/master/src/examples/pyNTAVIS_SNN_training_snnTorch.ipynb>`_
applies it to folders of AEDAT files with one subfolder per class.

.. note::
   The other splitters can also be used to build datasets: ``manual_splitter()`` extracts one portion of a recording,
   ``segmenter_RT()`` removes the background noise, and ``automatic_splitter()`` splits a recording into several files
   at the silences between sounds (its docstring notes that it needs more tests). See the
   :doc:`Splitters class <../pyNTAVIS.splitters>`.
